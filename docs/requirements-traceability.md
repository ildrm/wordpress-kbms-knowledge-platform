## How to maintain this matrix

Each exhaustive row maps one numbered brief section and all normative bullets within it. Because these parent requirements aggregate many features, a parent remains `N/S` until its complete scope meets the definition of done; delivered child slices are tracked above. During refinement, split rows into stable child IDs and never delete the parent source mapping.

Status vocabulary is defined in [README](README.md). `N/S` below means **Not started**, not “not supported.”
